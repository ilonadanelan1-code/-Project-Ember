# Tactical Controls — Project Ember v0.7.0

## Touch-first controls

- Friendly unit tap: select one unit.
- **ДОБОР** + friendly unit tap: add/remove a unit from the current selection.
- Drag-selection rectangle: select friendly units inside the rectangle.
- Selected units + enemy tap: focus-fire the tapped enemy.
- Selected units + ground tap: move to the selected formation. With **МАРШ** enabled this becomes attack-move.
- **ВСЕ** selects the entire player force.
- **ДЕРЖАТЬ** defends the current position; **СТОП** cancels orders; **ОТСТУП** withdraws selected troops.
- Formation cycles line, column and wedge.
- **ЗАПИСЬ** + **ГР. 1–4** saves the current selection to a control group. Tap a saved group button to recall it.
- Zoom buttons change camera distance. A second finger drag pans the battlefield; magnify gestures zoom when the device emits them.
- **БОЕВОЙ КЛИЧ** activates the ruler's commander ability. It heals nearby allies and grants a temporary damage/movement boost. The button displays cooldown.

## Keyboard controls

| Key | Action |
|---|---|
| A | Toggle attack-move orders |
| H | Hold selected units |
| S | Stop selected units |
| Q | Activate Battle Cry |
| Escape | Clear selection |
| R | Restart isolated battle |
| Arrow keys | Pan battlefield |
| Ctrl+1…4 | Assign selected units to a group |
| 1…4 | Recall a group |

## Unit roles

- **Swordsman:** durable general-purpose melee infantry.
- **Archer:** ranged damage, prefers to maintain distance, low armor.
- **Spearman:** armored front rank, extended reach and bonus damage against cavalry.
- **Cavalry:** fast flanking unit with a charge strike after a fast approach.
- **Commander:** persistent hero with a health bar, passive army aura, level-scaled combat stats and Battle Cry. Commanders are not counted against the 24-troop recruitment cap.

## Formation intent

- **Line:** spearmen front, swordsmen support, cavalry on wings, archers behind.
- **Column:** narrow marching column.
- **Wedge:** spear/sword forward wedge, cavalry on flanks and archers at the rear.
