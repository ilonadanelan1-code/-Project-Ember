Project Ember v0.9.0 — Foundation
- Centralized visual palette and Stylized Low-Poly Fantasy art bible.
- Shared runtime Theme for strategic and tactical UI, with readable base typography and minimum touch-target sizing.
- Independent player settings in user://settings.cfg: graphics quality, audio levels, UI scale, performance overlay, vibration and camera speed.
- Three graphics-quality tiers with a first-run mobile-aware quality heuristic.
- Performance overlay for FPS, draw calls, rendered objects, primitives, scene node count and available memory metrics.
- Cached runtime resources for procedural soldier/environment meshes and materials, plus the battlefield ground texture.
- Low quality disables dynamic battlefield shadows and reduces decorative scenery; higher tiers restore detail.
- Campaign save data, combat parameters, role IDs, formation slots, collision and input mappings remain unchanged.
- Godot CI and physical Android validation are required; phone performance, safe areas and touch response remain unverified.
