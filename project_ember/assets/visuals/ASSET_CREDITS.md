# Visual asset credits and licence notes

Project Ember integrates the following owner-supplied visual resources as a single game runtime atlas. The atlas is decoded by the Godot runtime; the original packs are not included as independent folders or offered as a standalone asset library.

- **Pixel Castle Medieval Tileset** — Copyright (c) 2026 reodesuxz. The supplied licence permits use and modification in personal and commercial projects. Attribution is not required; credit is included here.
- **Pixel Fantasy Monsters** — Copyright (c) 2026 reodesuxz. The supplied licence permits use and modification in personal and commercial projects. Attribution is not required; credit is included here.
- **Pixel Fantasy Monsters Vol. 2** — Copyright (c) 2026 reodesuxz. The supplied licence permits use and modification in personal and commercial projects. Attribution is not required; credit is included here.
- **Medieval RTS Army — Free Demo** — Copyright (c) 2026 Antahonist. The supplied licence permits modified sprites to be shipped inside released games; standalone redistribution, resale and AI-training use are not permitted. Credit is included here.
- **Factions Asset Pack** — Artwork by Scrython (Pixilart). The supplied README states that commercial use is permitted and attribution is not required; credit is included here.

The integrated runtime atlas is distributed only as part of Project Ember's game code and is not intended for extraction, resale, sublicensing or redistribution as an asset pack. No source images from the following archives are included because their supplied files did not contain a licence grant authorising this integration:

- coa-shields.zip
- 9 Heraldry constructor.zip

The atlas contains modified, packed and cropped game-use sprites. It is not an AI training dataset. Each upstream creator retains ownership of their original artwork. The game is provided without warranties beyond the licences supplied with those assets.
